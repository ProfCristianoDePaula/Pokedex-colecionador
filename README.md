# Carddex — coleção Pokémon TCG

Aplicação responsiva em React + Vite para acompanhar coleções, cartas faltantes, repetidas e trocas. Esta primeira versão é uma demonstração: os dados de coleção ficam salvos no navegador; login, mensagens e dados compartilhados ainda precisam ser conectados ao Supabase.

## Desenvolvimento
Execute `npm install` e `npm run dev`. Para gerar o site, use `npm run build`; os arquivos publicados ficam em `dist`.

## Cloudflare Pages
Conecte este repositório ao Cloudflare Pages. Comando de build: `npm run build`. Diretório de saída: `dist`. Configure a publicação automática na branch `main`.

## Catálogo e próximos passos
As cartas exibidas são exemplos ilustrativos e não uma checklist oficial completa. Antes de considerar o progresso definitivo, confira no catálogo os nomes, totais, cartas secretas e variantes de cada expansão. Login, inventário compartilhado, propostas e chat são etapas futuras com Supabase.
